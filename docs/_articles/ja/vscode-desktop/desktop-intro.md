Visual Studio Code 向け Salesforce 拡張機能は、Salesforce プラットフォームで開発するための豊富なツールを備えたオープンソースの拡張機能セットです。これらの拡張機能をダウンロードしてインストールすると、Salesforce プラットフォームでの開発を開始できます。

![Apex コードの補完、スクラッチ組織へのソースの push、Apex テストの実行を示す GIT](./images/overview.gif)

### オープンソース

- [ロードマップ](https://github.com/forcedotcom/salesforcedx-vscode/wiki/Roadmap)
- [Github リポジトリ](https://github.com/forcedotcom/salesforcedx-vscode)

## バグとフィードバック

VS Code 向け Salesforce 拡張機能 に関する問題を報告する場合は、[GitHub のバグ](https://github.com/forcedotcom/salesforcedx-vscode/issues/new?template=Bug_report.md)を登録してください。機能を提案する場合は、[GitHub で機能リクエスト](https://github.com/forcedotcom/salesforcedx-vscode/issues/new?template=Feature_request.md)を作成してください。
