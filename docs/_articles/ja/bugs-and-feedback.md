## Salesforce 拡張機能に関連する問題

これらの機能、または VS Code 向け Salesforce 拡張機能 に関連する他のあらゆる点に関する問題を報告する場合は、[GitHub のバグ](https://github.com/forcedotcom/salesforcedx-vscode/issues/new?template=Bug_report.md)を登録してください。

機能を提案する場合は、[GitHub で機能リクエスト](https://github.com/forcedotcom/salesforcedx-vscode/issues/new?template=Feature_request.md)を作成してください。

## Code Builder に関連する問題

Code Builder を使用していて何か問題が発生した場合、または最初の印象や機能リクエストなど、その他のフィードバックを提供したい場合は、GitHub リポジトリに [Issue を作成](https://github.com/forcedotcom/try-code-builder-feedback/issues)してください。どのような機能や改善があなたにとって重要なのかを理解したいと考えています。

## Einstein for Developers (ベータ) に関する問題

Einstein for Developers を使用していて何か問題が発生した場合、または最初の印象や機能リクエストなど、その他のフィードバックを提供したい場合は、GitHub リポジトリに [Issue を作成](https://github.com/forcedotcom/Einstein-GPT-for-Developers/issues)してください。どのような機能や改善があなたにとって重要なのかを理解したいと考えています。
